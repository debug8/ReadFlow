# Десктопна версія (Windows, WPF)

Настільний додаток для перевірки швидкості читання.

**Стек:** C#, WPF, .NET Framework 4.8
**Підтримка ОС:** Windows 7 SP1 → Windows 11

## Документація

- Специфікація: [`../docs/SPEC.md`](../docs/SPEC.md)
- Задачі для реалізації: [`../docs/TASKS.md`](../docs/TASKS.md)

## Складання

Відкрити `.sln` у Visual Studio 2019/2022 → Build. Жодних додаткових інсталяцій не потрібно: .NET Framework 4.8 уже вбудований у Windows 10 (1903+) та 11.

## Спільні дані

Норми WPM і тексти-зразки беруться з [`../shared/`](../shared/). Не дублюйте ці значення в коді — читайте з файлів, інакше десктоп і Android почнуть розходитись.

## Структура

```
desktop/
├── ReadFlow.sln
├── ReadFlow/              ← увесь код застосунку (Core, Models, ViewModels, Views, Data, Themes, Resources)
└── ReadFlow.Tests/        ← unit-тести (єдиний окремий проєкт)
```

## Теми оформлення

Кожна тема — окремий `ResourceDictionary` у `ReadFlow/Themes/`. Список тем у застосунку
не захардкоджений: `ThemeManager` читає таблицю ресурсів збірки й показує всі знайдені
`Themes/*.xaml`.

**Щоб додати свою тему:**

1. Скопіюйте `Themes/Light.xaml` під новою назвою (напр. `Sepia.xaml`).
2. Змініть `ThemeDisplayName` і значення кольорів. **Набір ключів чіпати не можна** —
   відсутній ключ ламає інтерфейс після перемикання.
3. Додайте файл до `ReadFlow.csproj` як `Page` (Visual Studio робить це сама при додаванні
   файлу до папки `Themes`).

Логіку правити не треба. Тест `AllThemes_HaveIdenticalKeySets` не дасть залити тему
з розбіжним набором ключів.
