# Десктопна версія (Windows, WPF)

Настільний додаток для перевірки швидкості читання.

**Стек:** C#, WPF, .NET Framework 4.8
**Підтримка ОС:** Windows 7 SP1 → Windows 11

## Документація

- Специфікація: [`../docs/SPEC.md`](../docs/SPEC.md)
- Задачі для реалізації: [`../docs/TASKS.md`](../docs/TASKS.md)

## Складання

Відкрити `.sln` у Visual Studio 2019/2022 → Build. Жодних додаткових інсталяцій не потрібно: .NET Framework 4.8 уже вбудований у Windows 10 (1903+) та 11.

## Спільні дані

Норми WPM і тексти-зразки беруться з [`../shared/`](../shared/). Не дублюйте ці значення в коді — читайте з файлів, інакше десктоп і Android почнуть розходитись.

> Проєкт ще не створено — почніть із Задачі 1 у `docs/TASKS.md`.
