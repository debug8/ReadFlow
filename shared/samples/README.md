# Тексти-зразки

Сюди складаються готові тексти для перевірки швидкості читання.

**Правила:**

- Один текст — один файл `.txt` у кодуванні UTF-8, без BOM.
- Імена файлів: `sample-NN.txt`, послідовна нумерація.
- Кожен файл обовʼязково реєструється в `index.json` (назва, клас, рівень, кількість слів).
- Поле `words` в `index.json` — фактична кількість слів за правилами з `docs/SPEC.md` (розділ 4). Заповнюйте після підрахунку самим додатком, не «на око».
- Тексти мають бути вільними від авторських прав (народні казки, класика в суспільному надбанні, власні тексти).

**Орієнтир за обсягом:** 1 клас — 40–80 слів, 2 клас — 80–150, 3 клас — 150–250, 4 клас — 250–400. Текст має бути помітно довшим за хвилинну норму класу, щоб учень не дочитав його до кінця раніше за таймер.

Файл `sample-01.txt` — заглушка; замініть реальними текстами.
